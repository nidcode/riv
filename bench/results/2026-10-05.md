## protocol

**Procedure.** Same ListSessions page (includeAbstracts=true, first page) fetched 3 times over REST, and over the remote MCP endpoint via rmcp's streamable-HTTP client with the same Bearer token. Bytes = REST body / MCP tool-result text.

| path | p50 ms | p95 ms | bytes (1 page) |
|---|---|---|---|
| REST ListSessions | 2 | 3 | 29084 |
| remote MCP | n/a | n/a | n/a |

Remote MCP was **not measured automatically**: the mock server has no /mcp endpoint

Manual measurement: connect Kiro or Claude Code to `http://127.0.0.1:35481/mcp`, sign in, ask for one page of sessions, and record wall-clock time and the size of the tool result shown in the transcript.
